## The conclusion that matters
**We optimised iPTM/RFD4 confidence while an unoptimised steric constraint decided eligibility.**
On the full cohort, PASS median iPTM **0.910** vs FAIL median **0.890** — a 0.020 gap — and
**85 of the 102 failures have iPTM ≥ 0.85**. Conversely **8 of the 78 passes are below 0.85**
(0.73, 0.77, 0.81, 0.81, 0.84, 0.84, 0.84, 0.84). So `0.85` is **neither necessary nor sufficient**
for eligibility: it keeps 85 designs the gate rejects and would have dropped 8 the gate accepts.
Rounds 1, 2, 3 and E3 all show the same structure — this is a pipeline property, not a one-off.

Both advisors' rulings (`decisions/20261025-r3-clash-dominance-{astra,kimi}.md`) agree: keep the
2.0 Å gate, **do not** relax it, **do not** cherry-pick a passing model, and change the *pipeline*
prospectively to select for geometry, measuring end-to-end gate yield rather than iPTM.
